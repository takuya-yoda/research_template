# 用語集（glossary）

対話で登場した学術用語の裏付け付き定義のキャッシュ．`/term <用語>` が参照・追記する．
再出現した語はここを引けば再検索なしで即座に一貫した説明を返せる（応答速度の核）．

各エントリは次の 3 点の裏付けを揃える方針（`/term` の運用規約）：
1. **用語辞典**に記載があること
2. **学部・大学院の標準教科書**に記載があること
3. その辞典・教科書が**世界中の学術機関で広く使われている**こと

各出典には確信度を付す：`検索確認済み`（web で当たった）／`訓練知識ベース`（未検索）／`推定`（③など soft な根拠）．
検証できなかった項目は空欄にせず `確認できず` と明記する（捏造しない）．

## エントリスキーマ

```markdown
## <用語>（訳語）
- 定義:
- 用語辞典: <辞典名・ID・URL>（確信度）
- 標準教科書: <著者, 書名（版）, 章>（確信度）
- 普及の根拠: <採用シラバス・叢書・書評 等の具体物>（確信度）
- 検証日: YYYY-MM-DD
- 関連: <関連語>
```
