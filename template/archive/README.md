# archive — 過去の遺産の保管庫

古いノート・旧バージョンの計算・使わなくなったコードなどを、閲覧できる状態で隔離する場所。

## ポリシー

- **ここのファイルは編集しない** (閲覧のみ)。編集したくなったら現行のフォルダへコピーしてから編集する
- ビルド・開発の対象外: LaTeX の自動コンパイルや Python パッケージには含めない
- 現行フォルダ (theory / survey / code) を整理する際、迷ったら消さずにここへ移動する
- 移動時はサブフォルダを切り、必要なら移動日と経緯を書いた短いメモを添える

```
archive/
└── 2026-07_old_bloch_note/
    ├── WHY.md      # いつ・なぜアーカイブしたか (1-2 行)
    └── ...
```
